# Security policy

Do not disclose vulnerabilities, credentials, access tokens, customer data or account identifiers in public GitHub issues.

Use Kiliba's established private security-reporting channel and include only the minimum information required to reproduce the issue. If that channel is unavailable, contact Kiliba support and request a private security handoff before sharing technical details.

The public repository contains documentation and client configuration examples only. The server implementation, infrastructure definitions and secrets are not published here.
